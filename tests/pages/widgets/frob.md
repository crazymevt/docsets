#### Syntax:

**frob** widget *&key* (hard t) => widget

#### Arguments and values:

*widget* -> a [widget](../widget).\
*hard* -> a [generalized
boolean](http://www.lispworks.com/documentation/HyperSpec/Body/26_glo_g.htm#generalized_boolean).

#### Description:

Frobs `widget`, harder when `hard` is true. See [frob](.).

- First.
- Second, which goes on
  to a second line.

```
(frob (make-widget))
```
